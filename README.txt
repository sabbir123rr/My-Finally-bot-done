Aimbot Files Bot — polling version

1. Open config.py and replace PASTE_YOUR_NEW_BOTFATHER_TOKEN_HERE with your NEW token.
2. Install dependencies: pip install -r requirements.txt
3. Run: python app.py

Bot must be admin in all required channels to check membership.
Bot must have permission to copy/post messages in the storage channel.
Keep config.py private; it contains your bot token.
